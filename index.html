find() : lire les documents

db.collection.find(query, projection, options) — renvoie un curseur vers les documents. Sans argument, retourne tous les documents.

ParamètreRôle
queryFiltre (opérateurs). {} ou omis = tous.
projectionChamps à renvoyer. Omis = tous.
optionsOptions supplémentaires.

Opérateurs de comparaison

OpérateurSignification
$eq / $neÉgal / différent
$gt / $gteSupérieur (ou égal)
$lt / $lteInférieur (ou égal)
$in / $ninDans / hors d'un tableau
db.Films.find({ annee: { $gt: 2010 } })
db.Films.find({ realisateur: { $in: ["Christopher Nolan", "James Cameron"] } })

Combiner des conditions

Plusieurs champs = ET implicite ($and). Pour un OU : $or.

db.Films.find({ titre: "Inception", annee: 2010 })       // AND
db.Films.find({ $or: [
  { realisateur: "Christopher Nolan" },
  { genre: "Science-fiction" }
] })                                                       // OR

Expressions régulières

MotifEffet
/star/iContient « star », insensible à la casse

/ar$/Finit par « ar »
/a.a/a + un caractère + a
/colou?r/color ou colour
db.Films.find({ $and: [
  { annee: { $gt: 2000 } },
  { titre: /ar/i }
] })

Sous-documents

db.Etudiants.find({ "adresse.ville": "Agadir" })

{ adresse: { ville: "Agadir" } } exige une correspondance exacte du sous-document.

Tableaux : positionnel

$ = première occurrence. $[elem] + arrayFilters = toutes les occurrences.

db.produits.updateMany({},
  { $set: { "avis.$[elem].note": 8 } },
  { arrayFilters: [ { "elem.client": "Amal" } ] })

Embedding ou referencing ?

Embedding = lecture optimisée. Referencing = écriture optimisée.

Embedding : lecture rapide, cohérence, pas de jointure, mais doc plus gros (16 Mo max), duplication, mises à jour lourdes. Referencing : pas de duplication, mises à jour simples, adapté au N-N, mais plusieurs requêtes ou $lookup.

Trois niveaux d'embedding

  • Simple : petit sous-document imbriqué.
  • Intermédiaire : tableau de sous-documents (un-à-plusieurs).
  • Avancé : imbrications profondes → $filter, $map, $reduce, $size, $slice, $arrayElemAt.

Pièges

  • Sous-document : notation pointée "adresse.ville".
  • Deux conditions sur le même élément : $elemMatch.
  • $all sur "matchs.adversaire", pas sur le tableau.
  • $pull retire TOUS les éléments correspondants.
  • replaceOne : aucun opérateur, tous les champs à réécrire.
  • Tri → skip → limit, toujours.
  • $arrayElemAt sur tableau vide : champ absent (pas d'erreur).

PHP : structures de contrôle

Un script PHP s'exécute par défaut séquentiellement. Les structures de contrôle modifient cet ordre : conditions (si une condition est vraie) et boucles (répétition).

Les opérateurs

FamilleOpérateurs
Arithmétiques+ - * / % **
Affectation= += -= *= /= .=
Incrémentation++ --
Comparaison== === != !== < > <= >= <=>
Logiques&& || !

Souple vs stricte

"7" == 7        // true
"7" === 7       // false
null == false   // true
null === false  // false
"1e3" == "1000" // true (piège !)

Règle : === et !== par défaut.

Falsy

false, 0, 0.0, "", "0", [], null. Court-circuit : A && B n'évalue pas B si A est faux ; A || B n'évalue pas B si A est vrai.

if / elseif / else

$note = 13.5;
if ($note >= 16)      { $m = "Très bien"; }
elseif ($note >= 14)  { $m = "Bien"; }
elseif ($note >= 12)  { $m = "Assez bien"; }   // ← ici
elseif ($note >= 10)  { $m = "Passable"; }
else                  { $m = "Non validé"; }

Tests dans l'ordre, du plus restrictif au plus large.

Bonnes pratiques

  • === par défaut.
  • Éviter les imbrications : combiner ou retour anticipé.
  • Toujours les accolades.
  • match pour associer valeur → résultat.

Personnaliser un bouton (styleFrom)

ElevatedButton(
  onPressed: () {},   // () {} = fonction vide
  child: Text("Click to begin"),
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.yellow,
    foregroundColor: Colors.black,
    elevation: 15,
    shadowColor: Colors.yellow,
    padding: EdgeInsets.all(20),
    shape: StadiumBorder(),          // pilule
    side: BorderSide(color: Colors.black, width: 2),
  ),
)

StadiumBorder = pilule. RoundedRectangleBorder(borderRadius: BorderRadius.circular(20)) = coins arrondis. side = bordure.

FloatingActionButton (FAB)

  • Cercle flottant, un seul par écran par défaut.
  • Actions positives : créer, partager, naviguer.
  • Déclaré dans le Scaffold via floatingActionButton:.
  • floatingActionButtonLocation change la position (ex. centerTop).
  • Plusieurs FAB : les mettre dans un Row ou Column.
Scaffold(
  floatingActionButton: FloatingActionButton(
    backgroundColor: Colors.orange,
    foregroundColor: Colors.white,
    onPressed: () { setState(() { compteur++; }); },
    child: Icon(Icons.add),
  ),
  floatingActionButtonLocation: FloatingActionButtonLocation.centerTop,
)

StatelessWidget vs StatefulWidget

StatelessWidgetStatefulWidget
ÉtatImmuableMutable
Mise à jourNonsetState(() { ... })
UsageContenu statiqueCompteur, formulaire, onglets
class Counter extends StatefulWidget {
  const Counter({super.key});
  @override
  State<Counter> createState() => _CounterState();
}
class _CounterState extends State<Counter> {
  int n = 0;
  @override
  Widget build(BuildContext context) {
    return FloatingActionButton(
      onPressed: () => setState(() => n++),
      child: Text('$n'),
    );
  }
}

Pièges et bonnes pratiques

  • Un FAB par écran par défaut ; plusieurs seulement via Row/Column.
  • onPressed: () {} = fonction vide : bouton cliquable mais qui ne fait rien.
  • TextEditingController doit être branché via controller:.
  • validator retourne String? : message si invalide, null si valide.
  • Pour changer le texte d'un bouton, stocker le texte dans une variable d'état et la modifier via setState.
  • import 'package:flutter/material.dart'; obligatoire.
  • Image.asset(fit: BoxFit.cover) + ClipOval pour une image ronde.
