Transmission et modulation

Pourquoi moduler ? Réduire les dimensions de l'antenne : L = λ/4 = c/(4f). Pour f = 1 MHz, λ = 300 m, L = 75 m (raisonnable).

Signal modulant (message, BF) + porteuse (HF). x(t) = A cos(θ(t)).

TypeParamètre modulé
AMAmplitude A
FMFréquence (dans θ)
PMPhase (dans θ)

Modulations analogiques : AM, FM, PM. Modulations numériques : ASK, FSK, PSK.

Pièges

  • Unités : Mo vs Mb (×8). 16 Mo / 16 Mb/s = 8.38 s (16 Mo = 2²⁴ octets).
  • Manchester : R = 2D (2 transitions par bit).
  • Shannon donne un maximum ; S/N en dB → 10^(dB/10).
  • dBm : toujours référencé au milliwatt.
  • Antenne : L = c/(4f), c = 3×10⁸ m/s.
